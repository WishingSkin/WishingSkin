# 界面与首页设置

管理员进入“管理后台 → 站点设置 → 个性化”，即可统一调整站点品牌、公告、主题包、面板效果、首页区块与登录页配图。

## 保存机制与导航交互

- 修改任意区块后，屏幕底部会浮现“保存全部”浮动栏；在设置分类间切换会保留当前草稿，半透明/毛玻璃效果与页面滚动均不影响保存栏固定位置。
- 顶部导航栏保留公开库、公告和账号菜单入口。点击头像可切换语言、明暗模式、查看账号或退出；未登录访客也可在账号菜单中调整界面偏好。
- 主动切换明暗模式时，支持 View Transitions 的浏览器会播放 250ms 柔和过渡；首次加载、开启系统“减少动态效果”或不支持该 API 时直接生效。快速连续切换以最后一次选择为准。

## 外观、主题与面板效果

- **站点 Logo**：支持上传 PNG 或 JPEG（最大 512 KiB、2048×2048），服务端自动规范为最长 512 px 的正方形 PNG；未上传时显示自适应主题色的“星芒立方”矢量图标。
- **主题包、材质与字体**：内置默认 + 13 套主题（含 8 套 Minecraft 实景主题与像素氛围粒子）、`client.jar` / 资源包贴图提取、3 套开源像素字体及自定义 WOFF2 字体，并支持开放访客本地自选。详细说明见[主题包、材质与字体指南](themes-and-assets.md)。
- **面板效果**：可选实色、半透明或毛玻璃。选择半透明时可微调**面板不透明度**（`35%–98%`），选择毛玻璃时可同时微调**毛玻璃模糊度**（`4–36 px`），拖动滑块时页面会实时预览效果，未保存离开会自动恢复原配置。输入框始终保留清晰可读底色；系统开启“减少透明度”时自动回退为实色。
- **高级界面设置**：
  - **界面颜色**：按浅色、深色分别覆写 17 项颜色 token。自定义颜色优先于主题包，切换主题包会保留这些覆写；清空某项后恢复为当前主题默认色。
  - **界面文案**：按简体中文和 English 分别覆写界面纯文本，清空即恢复该语言默认文案。公告支持纯文本或经安全过滤的 Markdown，保存后进入历史公告列表，支持在后台单独删除不再需要的历史公告（删除当前公告时同步撤下首页展示）。
  - **导航图标**：可覆盖侧栏和常用入口的短文本符号；首页主标志与功能卡图标在下方首页区块中单独配置（支持 PNG/JPEG 上传、HTTPS URL 或站内根路径）。

## 登录页图片

- 显示在登录页左侧，上传时保留 PNG 透明通道（JPEG 保持 JPEG），最长边缩放至 1920 px 以内。
- 若早期版本保存过自动合白底的图片，重新上传原始透明 PNG 即可恢复透明效果。

## 首页区块与背景

首页最多配置 8 个区块，按后台顺序展示，支持单独启停、上下移动和删除：

- **区块名称**：仅用于在后台列表区分，不会展示在公开首页。
- **首页大图与遮罩**：上传自定义首页背景时，遮罩浓度可在 `0–100%` 间自由调节；未上传自定义背景且启用 MC 群系主题时，首页自动启用对应的 16:9 实景双幕背景。
- **展示区（Showcase）**：可添加多个展示区，既支持**自定义图文**——上传 PNG/JPEG（最大 2 MiB、4096×4096，保存后最长边不超过 1920 px 且保留 PNG 透明度）、HTTPS URL 或以 `/` 开头的站内路径，也支持直接切换展示公开库的**近期热门 / 点赞最多 / 收藏最多**动态材质橱窗。单次首页保存请求上限为 12 MiB。
- **资源路径说明**：站内路径必须是浏览器实际可访问的地址，不能填写服务器或电脑本地磁盘路径；外部链接由访客浏览器直接拉取，请确保长期可用。

## 浏览体验与穿戴

- 公开库、我的衣柜与我的材质列表均使用静态人物模型缩略图，点开详情后再加载可交互 3D 舞台，兼顾流畅度与预览效果。
- 搜索框与材质类型固定在同一行；公开库的分类、标签和排序收在“更多筛选”折叠区，收起时保留条件并展示当前生效的筛选数量。加载中显示骨架屏（开启“减少动态效果”时保持静态）。
- 皮肤、披风平面图与像素装饰图默认使用 `pixelated` 渲染，放大后保留锐利像素边缘。
- 应用皮肤时可单独指定该角色使用标准或纤细手臂，不改写原材质记录的默认模型；应用披风保留现有皮肤与手臂模型。

## 备份时区与管理记录

- “存储与备份”中的备份时区按 IANA 地区时区保存（界面同步显示城市名与当前 UTC 偏移），夏令时地区会随日期自动切换，每日备份始终按所选地区本地时间触发。
- 管理后台的所有保存操作都会记录字段级前后变更并支持 CSV 导出；密码、密钥、凭据和图片/贴图大对象仅记录更新标记，不写入明文或大文本。历史旧记录保持原样，不补造缺失详情。
