# 界面与首页设置

管理员进入“管理后台 → 站点设置 → 个性化”。修改文案、外观、首页或登录图片后，使用浮动的“保存全部”按钮保存。切换设置分类会保留草稿。

## 首页区块

首页最多包含 8 个区块，按后台列表顺序显示。每个区块可单独启停、移动或删除。

- 区块名称用于后台识别，不显示在公开首页。
- 区块标题和正文显示在首页。正文支持换行，使用纯文本。
- 展示区支持文字和一张配图。可以添加多个展示区。
- 按钮可链接到站内路径或 HTTPS 地址。

展示图片支持 PNG、JPEG、HTTPS URL 和以 `/` 开头的站内资源路径。上传文件不得超过 2 MiB，原图最大为 4096×4096。保存后最长边不超过 1920px，保持比例；PNG 保留透明度。单次首页设置请求上限为 12 MiB，包含背景和所有区块的图片编码。

站内资源路径必须能通过浏览器访问。本机或服务器磁盘路径不能直接用作图片地址。外部图片由浏览器请求，需使用长期可访问的地址。

## 浏览与穿戴

公开库、我的衣柜和我的材质使用人物模型的静态缩略图。打开详情后显示可旋转模型。

应用皮肤时，可为目标角色选择标准或纤细手臂。此选择只改变该角色，不修改上传材质的默认模型。应用披风保留角色原有皮肤和手臂模型。

## 备份时区

“存储与备份”显示城市名称和当前 UTC 偏移。保存使用地区时区，而不是固定偏移。使用夏令时的地区会随日期切换偏移；每日备份仍按所选地区的本地时间执行。

## 管理记录

新操作会记录字段和修改前后值。密码、访问密钥和其他凭据仅记录更新标记。图片内容不写入记录。CSV 导出包含字段变更。

历史记录保留原操作、目标和时间，不补造缺失的字段详情。管理记录及字段详情随完整备份保存。升级和恢复规则见[升级手册](upgrade-runbook.md)与[备份手册](backup-restore.md)。
