# 界面与首页设置

管理员进入“管理后台 → 站点设置 → 个性化”。修改文案、外观、首页或登录图片后，使用浮动的“保存全部”按钮保存。切换设置分类会保留草稿。

有改动时，保存栏固定在屏幕底部。保存后再次修改会重新出现；半透明、毛玻璃和页面滚动不改变保存栏位置。

顶栏保留公开库、公告和头像入口。点击头像打开账号菜单，可切换语言、明暗模式、查看账号或退出登录。未登录时，账号菜单提供登录和界面偏好设置。

从账号菜单切换明暗模式时，支持 View Transitions 的浏览器使用 250ms 淡入淡出。首次加载、开启“减少动态效果”或不支持该 API 时直接应用主题。快速重复切换以最后一次选择为准。

## 外观与文案

个性化包含品牌、公告、首页、登录图片和外观设置。背景遮罩可调 0–100%。内容面板可选择实色、半透明或毛玻璃，输入框保留清晰底色；系统要求减少透明度时使用实色。

“主题包”提供默认外观和 16 套配色，每套均包含浅色与深色模式。选择“默认”时，可单独选择主题配色；其他主题包使用自身配色。切回默认会保留之前选择的配色。主题包、站点默认明暗模式和面板效果均通过“保存全部”生效，用户自己的明暗选择优先。

页面底部的高级界面设置按浅色、深色分别配置颜色。文案覆盖按简体中文和 English 分别保存，清空覆盖后恢复该语言的默认文案。界面文案使用纯文本；公告可单独选择纯文本或经安全过滤的 Markdown。

高级设置中的自定义颜色优先于主题包。切换主题包会保留这些颜色；清空某项颜色后，该项恢复为所选主题包的颜色。MC 官网与 Wiki 选项提供相应配色。

首页标志和功能卡图标可上传 PNG/JPEG，也可填写 HTTPS URL 或站内根路径。文本导航图标单独设置。登录页图片保留 PNG 透明度；以前已保存成白底的图片需重新上传透明原图。

## 首页区块

首页最多包含 8 个区块，按后台列表顺序显示。每个区块可单独启停、移动或删除。

- 区块名称用于后台识别，不显示在公开首页。
- 区块标题和正文显示在首页。正文支持换行，使用纯文本。
- 展示区支持文字和一张配图。可以添加多个展示区。
- 按钮可链接到站内路径或 HTTPS 地址。

展示图片支持 PNG、JPEG、HTTPS URL 和以 `/` 开头的站内资源路径。上传文件不得超过 2 MiB，原图最大为 4096×4096。保存后最长边不超过 1920px，保持比例；PNG 保留透明度。单次首页设置请求上限为 12 MiB，包含背景和所有区块的图片编码。

站内资源路径必须能通过浏览器访问。本机或服务器磁盘路径不能直接用作图片地址。外部图片由浏览器请求，需使用长期可访问的地址。

## 浏览与穿戴

公开库、我的衣柜和我的材质使用人物模型的静态缩略图。打开详情后显示可旋转模型。

搜索与材质类型排列在同一行。公开库的分类、标签和排序放在“更多筛选”中，收起后保留当前条件，并显示已设置的条件数量。列表加载时显示骨架屏；开启“减少动态效果”后，骨架屏保持静态。

皮肤、披风、模型缩略图和首页展示图片使用像素渲染，放大时保留像素边缘。

应用皮肤时，可为目标角色选择标准或纤细手臂。此选择只改变该角色，不修改上传材质的默认模型。应用披风保留角色原有皮肤和手臂模型。

## 备份时区

“存储与备份”显示城市名称和当前 UTC 偏移。保存使用地区时区，而不是固定偏移。使用夏令时的地区会随日期切换偏移；每日备份仍按所选地区的本地时间执行。

## 管理记录

新操作会记录字段和修改前后值。密码、访问密钥和其他凭据仅记录更新标记。图片内容不写入记录。CSV 导出包含字段变更。

历史记录保留原操作、目标和时间，不补造缺失的字段详情。管理记录及字段详情随完整备份保存。升级和恢复规则见[升级手册](upgrade-runbook.md)与[备份手册](backup-restore.md)。
