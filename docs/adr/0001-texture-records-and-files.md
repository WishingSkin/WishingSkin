# ADR 0001：分离材质记录与图片文件

## 状态

已接受

## 背景

Blessing Skin 为材质条目分配独立 ID，并以 hash 指向 PNG 文件。同一文件内容可以对应多个条目，各自拥有名称、上传者和公开状态。WishingSkin 早期表以 hash 作为材质主键，无法表达这些独立条目，也无法无损导入重复 hash 的来源记录。

## 决策

将材质记录与材质文件分开建模。材质记录保存所有者、名称、描述、类型、模型和公开状态，并引用按 hash 去重的文件。角色和 Yggdrasil 资料继续使用稳定材质文件 hash 获取 PNG；衣柜和公开库关联材质记录。

“未公开”作用于材质记录：它隐藏该条目的公开资料，不阻止持有文件 URL 的客户端取材。删除条目时，只有在没有其他有效条目或角色绑定引用文件后，才可停止提供或清理相应文件。

## 结果

迁移可以保留多个来源条目对同一 hash 的独立元数据；材质库也能分别呈现上传者的多个条目。数据库升级需要为现有按 hash 保存的行建立兼容映射；升级、删除和重新上传必须保留共享文件引用。
