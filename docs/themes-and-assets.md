# 主题包、Minecraft 材质与字体指南

管理员进入“管理后台 → 站点设置 → 个性化”，即可配置主题包、面板材质、Minecraft 客户端贴图导入和界面字体。

## 主题包一览

系统内置“默认”与 13 套主题，共 14 套。除“深暗之域”锁定深色外，其余主题均同时支持浅色与深色模式。

### Minecraft 群系与维度主题（8 套）

8 套 MC 主题采用“浅色对应地上/表层、深色对应地下/暗面”的成对设计，内置 15 张 16:9 体素实景壁纸与全群系原版像素氛围粒子：

| 主题 | 浅色场景（地上/表层） | 深色场景（地下/暗面） | 氛围粒子 |
| --- | --- | --- | --- |
| 平原（`plains`） | 草原、草方块与橡木 | 废弃矿井、深板岩与矿石 | 橡木树叶、萤火虫 / 矿洞星尘 |
| 雪原（`snowy`） | 冰封山峰、冰刺与云杉 | 26.4 冰洞、发光冰晶与方解石 | 飘雪微尘 / 冰晶微光 |
| 丛林（`jungle`） | 热带雨林与竹林 | 繁茂洞穴、苔藓与孢子花 | 丛林树叶、萤火虫 / 荧光微尘 |
| 沙漠（`desert`） | 沙漠与砂岩 | 沙漠神殿密室与彩陶考古 | 浮沙微尘 / 火花星尘 |
| 樱花（`cherry`） | 樱花树林 | 紫水晶洞与晶簇 | 樱花花瓣 / 紫晶星闪 |
| 下界（`nether`） | 绯红森林与菌光体 | 诡异森林、黑石与玄武岩 | 火焰火星 / 灵魂火与辉光 |
| 末地（`end`） | 末地城、紫珀与末地石砖 | 虚空外岛与黑曜石 | 末地星闪 / 虚空微光 |
| 深暗之域（`deep_dark`） | 仅深色（自动隐藏明暗切换） | 远古城市、幽匿块与强化深板岩 | 幽匿灵魂上升 |

- **首页双幕展示**：未设置自定义首页大图时，浅色模式在顶部展示地上实景，向下滚动时平滑过渡到地下实景；深色模式直接展现地下/暗面实景。
- **工作台与公开库**：以柔和底纱固定展示当前实景，搭配半透明或毛玻璃面板可获得更佳层次感。
- **氛围粒子**：低密度贴合页面左右两侧运动，避开正文阅读区；支持后台全局开关与用户在账号菜单中单独开关，开启系统“减少动态效果”时自动隐藏。

### MC 社区风与通用主题（5 套）

- **MC 官网风（`mc_official`）**：深炭顶栏与草绿按压按钮风格。
- **MC Wiki 风（`mc_wiki`）**：石质顶栏、经典蓝链与工具书框线。
- **Nord 极光（`nord`）**：北欧冷灰蓝与极夜深色配色。
- **纸张阅读（`paper`）**：暖白宣纸与低眩光暖墨配色，适合长阅读。
- **高对比无障碍（`high_contrast`）**：纯白黑字 / 纯黑白字，加强边框与焦点轮廓。

选择“默认”主题时，可额外搭配 7 种主题配色（蓝、绿、紫、玫瑰、橙、青、石墨）；切换其他主题再切回默认时，原配色会保留。

## Minecraft 材质资源导入

系统采用“开箱即用 + 按需提取”的双层架构，未上传任何游戏文件时所有主题均可直接使用：

- **默认内置层**：前端动态生成轻量 16×16 像素方块纹理与 8×8 锐边像素粒子。
- **导入原版或资源包层**：管理员在“Minecraft 方块材质资源”区域上传 Minecraft 客户端 `client.jar` 或任意资源包 `.zip`（最大 80 MiB）。
  - 服务端按白名单提取 112 张贴图（94 个方块键 + 18 个 `assets/minecraft/textures/particle/` 粒子键），自动裁剪动画贴图首帧，并按群系温度/湿度读取 `colormap/grass.png` 与 `foliage.png` 完成染色合成。
  - 贴图会重新编码为 PNG，与元数据分表行存入数据库，并在升级后保持原有 `/api/theme-assets/{version}/{key}.png` 访问地址；原始 `.jar` 或 `.zip` 在提取完成后立即删除。
  - 导入后的方块贴图会以完整像素正方形展示在主题选择卡片与后台预览条中，粒子贴图会直接替换首页氛围粒子。
- **合规说明**：启用 MC 系列主题或已导入 Minecraft 贴图时，页脚会自动展示非官方合规声明。

## 界面字体

支持自由切换字体预设与应用范围（“仅标题与品牌”或“全局界面”）：

| 预设 | 说明 |
| --- | --- |
| 系统默认（`system`） | 原生无衬线字体，零额外下载 |
| Monocraft（`monocraft`） | 英文与数字使用 MC 像素体，中文保持系统清晰字体 |
| 缝合像素（`fusion_pixel`） | 英文 Monocraft + 简体中文 Fusion Pixel 12px 点阵字体 |
| 方舟像素（`ark_pixel`） | 英文 Monocraft + 简体中文 Ark Pixel 12px 硬朗像素体 |
| 自定义字体（`custom`） | 上传不超过 2 MiB 的 WOFF2 字体文件（服务端校验 `wOF2` 魔数），或填写 HTTPS / 站内字体地址（填写地址时优先使用地址；CSS 样式表会自动解析 `?family=` 参数，也可手动指定字体族名称） |

上传的字体文件与元数据分开保存，升级后仍保留原访问地址。

内置像素字体均采用 SIL OFL 1.1 开源许可，按需懒加载，许可全文见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 面板效果与用户偏好

- **面板效果**：可选实色、半透明或毛玻璃。选择半透明时可微调**面板不透明度**（`35%–98%`），选择毛玻璃时可同时微调**毛玻璃模糊度**（`4–36 px`）；系统开启“减少透明度”时自动回退为实色。
- **允许用户自选**：管理员勾选“允许用户在账号菜单中自行切换主题包与字体偏好”后，访客与登录用户均可在右上角账号菜单中按个人喜好覆盖站点默认主题、字体与粒子开关（保存在浏览器本地，不影响其他用户）。
