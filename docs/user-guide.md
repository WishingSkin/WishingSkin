# 使用指南（玩家与站长）

本指南面向首次接触 WishingSkin 的玩家与站长，介绍日常外观管理、游戏启动器接入和后台常用设置。生产部署与环境变量见[生产自部署手册](deployment.md)和[配置与 CLI 参考](configuration.md)。

## 玩家上手

### 1. 注册、登录与安全

- 访问站点首页并点击“登录工作台”。若站点开放注册，可在登录页底部进入“创建账号”。
- 若站点启用邮件验证，注册后请点击邮件中的链接激活账号；若启用管理员验证，提交后等待管理员在后台完成审核即可登录。
- 登录后进入“账号 → 个人资料与安全”，可修改昵称、头像（默认头像、自定义图片或自动截取角色皮肤头像），并可开启 TOTP 两步验证或绑定 OIDC / 外部账号。
- 修改密码会撤销当前账号的所有网页会话与游戏令牌，网页与启动器均需重新登录。

### 2. 创建角色与 3D 预览

- 进入“角色管理”创建新角色，角色名支持 3–16 位英文字母、数字和下划线。
- 每个角色拥有稳定的 UUID，改名不会改变 UUID。默认每账号可创建 1 个角色，站长可在后台调整上限。
- 选中角色后可在 3D 舞台中拖动旋转、滚轮缩放、切换正背面以及启停自动旋转或走动；若浏览器开启系统“减少动态效果”，自动动画会自动关闭。

### 3. 上传与穿戴皮肤、披风

进入“我的材质 → 上传材质”，上传 PNG 图片后即可 3D 预览并应用到角色：

| 材质类型 | 文件与尺寸要求 | 说明 |
| --- | --- | --- |
| 皮肤（Skin） | PNG，最大 8 MiB；支持 `64×64`、`64×32`、`128×128`、`128×64` | 上传时选择默认手臂模型（标准 Steve / 纤细 Alex）；穿戴到角色时可为该角色单独覆盖手臂模型，不影响原材质记录 |
| 披风（Cape） | PNG，最大 8 MiB；宽度 `64–1024 px` 且为 64 的倍数，宽高比 `2:1` | 应用披风不会覆盖角色现有的皮肤和手臂模型 |

- 勾选“公开这份材质”后，其他用户可在“公开库”浏览并收藏到衣柜；取消公开会将其从公开库隐藏，但不影响已收藏或已穿戴的角色，持有直链的客户端仍可加载。
- 若站点开启上传审核，新上传或编辑资料后的材质需经管理员审核通过，方可下载与穿戴。

### 4. 公开库与我的衣柜

- **公开库**：按关键词、材质类型（皮肤/披风）、分类、标签和排序筛选全站公开材质，点击卡片打开 3D 详情，可一键收藏到衣柜或直接应用到指定角色。
- **我的衣柜**：集中管理收藏的材质，可为每件收藏设置个人别名（不影响原作者的材质名称），方便在不同角色间快速切换。

### 5. 接入 Minecraft 游戏

登录后进入“账号 → 游戏接入”页面，直接复制当前站点的接入地址：

#### 方式一：Yggdrasil 外置登录（推荐，支持完整身份认证与皮肤披风）

1. 在本站创建角色并绑定皮肤或披风。
2. 在支持 `authlib-injector` 的启动器（如 PCL2、HMCL、Prism Launcher）中添加外置登录认证服务器，填入页面显示的**外置登录地址**（形如 `https://你的域名/api/yggdrasil/`）。
3. 使用**本站注册邮箱与本站密码**登录并选择角色。注意：TOTP 与 OIDC 仅保护网页登录，不会改变游戏密码。
4. 联机服务端同样需要挂载 `authlib-injector`，在启动命令的 `-jar` 参数之前添加：

```text
-javaagent:/path/to/authlib-injector.jar=https://你的域名/api/yggdrasil/
```

#### 方式二：CustomSkinLoader / 传统链接（仅加载外观，不接管账号认证）

- 点击“下载 CustomSkinLoader 配置”获取 `CustomSkinLoader.json`（优先查本站，未命中时回退 Mojang），合并到客户端配置前建议先备份原文件。
- 如使用支持传统 URL 模板的加载器，可复制页面中的皮肤/披风模板，将其中的 `{USERNAME}` 替换为角色名。

## 站长日常管理

管理员登录后，左侧导航栏会出现“管理后台”入口，包含以下常用模块：

- **用户管理**：搜索用户、封禁/解封、调整管理员权限（系统会保护最后一名可用管理员不被误删权）以及在无 SMTP 模式下手动完成邮箱验证。
- **角色 / 材质 / 衣柜管理**：检索并维护全站角色与材质；如遇违规内容可下架整份图片文件（同一文件关联的所有记录与穿戴会一并停用）。
- **举报管理**：处理用户提交的材质举报；从 Blessing Skin 迁入的历史举报会在独立只读区域展示。
- **管理记录**：查看全部成功的后台操作与字段级前后变更，支持中英文关键词或 `#编号` 检索，并可导出 CSV。
- **站点设置**：
  - **个性化**：配置站点 Logo、14 套主题包、像素字体、Minecraft `client.jar` 材质导入、面板半透明/毛玻璃与不透明度/模糊度、首页区块与背景、登录页图片及高级颜色/文案覆写，详情见[界面与首页设置](interface-customization.md)与[主题包、材质与字体指南](themes-and-assets.md)。
  - **账号与注册**：调整每账号角色上限、注册模式、邮箱域名白黑名单、验证方式及用户 ID 分配方式。
  - **邮件与验证**：配置 SMTP 发信与 Cloudflare Turnstile 人机验证，并可直接在页面测试连通性。
  - **存储与备份**：启用每日定时完整备份、配置保留份数、查看与校验备份、配置公开材质 CDN 以及同步或回收孤立存储文件。
- **插件管理**：启停官方模块（邀请码、积分、OIDC、本站 OAuth2、外部账号连接器、S3 对象存储），或上传 ZIP / 配置静态市场源安装社区插件及 Webhook。
