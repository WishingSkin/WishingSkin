# 功能与限制

## 账号与角色

| 功能 | 当前行为 |
| --- | --- |
| 本地账号 | 注册、登录、退出、密码修改和找回；新 ID 默认递增，可选 10 位随机数字 |
| 注册规则 | 开放或关闭注册、邮箱域名白黑名单、Turnstile；默认邮件验证，可选管理员验证 |
| 登录保护 | TOTP、本地二维码、一次性恢复码；密码正确后进入第二步验证 |
| 角色 | 多角色、改名、删除、稳定 UUID、皮肤与披风绑定；默认每账号 1 个角色，上限可调整 |
| 外置登录 | Yggdrasil / authlib-injector，角色选择、令牌更新与撤销、进服验证和签名资料 |
| 用户管理 | 封禁、权限调整、手动完成邮箱验证；保护最后可用管理员 |

## 材质与界面

| 功能 | 当前行为 |
| --- | --- |
| 上传 | PNG 最大 8 MiB；新皮肤支持 64×64、64×32、128×128、128×64；披风宽度 64–1024px 且为 64 的倍数，宽高比 2:1 |
| 材质记录 | 名称、简短描述、公开状态、分类和标签；相同文件可有独立记录 |
| 浏览 | 公开库、我的材质、衣柜；统一搜索栏和类型筛选、服务端分页；静态人物缩略图及可旋转详情模型 |
| 穿戴 | 从详情或角色页选择皮肤、披风；角色可覆盖标准或纤细手臂模型 |
| 审核与举报 | 上传前审核默认关闭；待审和拒绝材质不可下载或穿戴；支持举报和后台处置 |
| 个性化 | 中英文文案分别覆盖、浅深配色、半透明与毛玻璃、Logo 和图标、背景、透明登录图片、多块图文首页 |
| 交互 | 统一模态确认、Toast、顶栏公告、固定导航、独立子页地址和局部切换动画；支持减少动态效果与明暗切换过渡 |

“未公开”隐藏公开库和公共详情，持有文件 URL 的客户端仍可取材。审核、下架和删除使用独立规则。

## 官方插件与社区扩展

| 功能 | 当前行为 |
| --- | --- |
| 邀请码 | 可选必填、次数和期限、批量生成及导出；保留本站注册验证规则 |
| 积分 | 默认关闭；可配置北京时间每日签到奖励、上传费用和新建角色费用 |
| OIDC | 最多 12 个提供商；主动绑定、确认账号、登录和按本站规则创建新账号 |
| 本站 OAuth2 | 授权码 + PKCE S256，公开与机密客户端，profile/email 只读 scope，同意与撤销 |
| 外部账号 | AuthMe 只读 MySQL 和通用 HTTP 主动绑定；不使用外部密码直接登录本站 |
| S3 存储 | 保留本地副本、远程读取与故障回退、既有材质幂等同步 |
| 社区插件 | Go SDK 随源码编译；独立配置和启停、受控路由、提交后事件、管理员内容页、手动及固定间隔任务 |

OAuth2 不提供 refresh token 或 ID token。社区插件与宿主同进程运行；动态安装、热加载、插件市场、任意前端模块、Webhook 和插件 SQL 迁移执行尚未提供。Passkey 与 Minecraft 正版持有验证及绑定尚未实现。

## 运维与迁移

支持 MySQL 8 和 PostgreSQL。提供健康检查、管理字段变更记录及 CSV 导出、完整备份、每日固定时区备份、隔离恢复、旧材质同步、孤立文件回收和公开材质签名 CDN。

回收只处理无数据库记录且超过一小时的本地孤立文件，不枚举全部远端对象。备份保留本地材质，设置密钥单独保管；旧副本的保留策略由维护者安排。恢复使用匹配 schema 的程序和独立空目标，不支持在线覆盖恢复或自动降级。

BS 迁移支持固定的 6.0.2 来源及指定传统 Yggdrasil 插件，保留账号、角色实际 UUID、材质和声明的关系数据。未知插件、任意运营配置和 PHP 插件运行不迁入。详细范围见[来源契约](bs-source-contract.md)，操作见[迁移手册](migration-runbook.md)。
