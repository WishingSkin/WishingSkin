# 功能与限制

本文列出 WishingSkin 当前版本（schema 29）已实现的能力以及明确未覆盖的边界。

## 账号与角色

| 模块 | 当前支持 |
| --- | --- |
| 本地账号 | 注册、登录、退出、密码修改与邮箱找回；新账号 ID 默认递增，可切换为 10 位随机数字（已有 ID 保持不变） |
| 注册控制 | 关闭/开放注册、邮箱域名白黑名单（黑名单优先）、Cloudflare Turnstile；支持邮件验证或管理员手动激活 |
| 登录保护 | TOTP 两步验证、本地二维码、一次性恢复码；仅保护网页密码与 OIDC 登录 |
| 角色管理 | 多角色、改名、删除、稳定 UUID（改名不重算）、皮肤与披风独立绑定；支持全站默认角色上限与按用户独立上限覆盖 |
| 外置登录 | Yggdrasil / authlib-injector 认证、可选角色名/非邮箱登录（`feature.non_email_login`）、角色选择、令牌刷新与撤销、进服校验和 RSA 签名资料 |
| 用户管理 | 封禁/解封、调整管理员权限、手动完成邮箱验证、调整单用户积分（写入流水与审计）、设置/清除独立角色上限、管理员重置密码（撤销全部会话与游戏令牌）；自动保护最后一名可用管理员 |

## 材质、主题与界面

| 模块 | 当前支持 |
| --- | --- |
| 材质上传 | 默认 PNG 最大 8 MiB、皮肤 `64×64`/`64×32`/`128×128`/`128×64`、披风 `64–1024 px`（64 倍数，2:1）；后台可按策略配置皮肤/披风最大宽度（`64–1024 px`）与文件上限（`1–8 MiB`），上传表单支持拖拽与本地预检 |
| 材质记录 | 名称、描述、公开状态、分类与标签；同一图片文件可关联多条独立记录（按 hash 去重存储） |
| 浏览与筛选 | 公开库、我的材质、个人衣柜；统一搜索栏与类型筛选、服务端分页；支持材质点赞、近期热门 / 最新上传 / 点赞最多 / 收藏最多榜单、公开详情分享链接（`/library/{id}`）与首页热门材质橱窗；静态模型缩略图与增强 3D 详情（动作、外层开关、披风/鞘翅切换、导出 PNG 立绘） |
| 穿戴绑定 | 从角色页或材质详情直接应用皮肤与披风；穿戴皮肤时可为单个角色覆盖标准/纤细手臂模型 |
| 审核与举报 | 上传审核默认关闭；待审与已拒绝材质不可下载或穿戴；支持用户举报、后台处置及 BS 只读历史举报 |
| 个人通知 | 顶栏个人通知收件箱（分页、单条/全部已读、未读角标）；材质审核、举报处置、图片下架及管理员调分/改上限/手动验邮自动入箱，支持可选邮件投递 |
| 批量导入 | `import-textures` CLI 子命令支持目录或递归导入 PNG、自动区分皮肤/披风、`--dry-run` 预检、内容去重、配额与审核遵循，并输出 JSON 报告 |
| 主题与字体 | 默认 + 13 套主题（含 8 套 MC 地上/地下成对实景壁纸与全群系原版像素粒子）、`client.jar`/资源包 112 键贴图提取、内置 3 套 OFL 1.1 像素字体与自定义 WOFF2/URL 字体、用户本地偏好覆盖 |
| 界面定制 | 面板实色/半透明/毛玻璃及不透明度（`35%–98%`）和模糊度（`4–36 px`）调节、Logo 与图标、自定义背景与保留透明度的登录页配图、最多 8 个首页图文区块、中英文文案覆写及浅深高级配色 |
| 交互体验 | 统一模态确认框、Toast 提示、顶栏公告、独立可刷新子页路由与局部过渡动效；支持编辑/密钥弹窗防误关、跨页未保存确认、`Ctrl/Cmd+S` 保存、一键复制与明暗/减弱动效适配 |

> [!NOTE]
> “未公开”仅隐藏公开库与公共详情，持有有效图片直链的客户端仍可加载；审核未通过、整图下架与删除遵循独立的访问拦截规则。

## 官方插件与社区扩展

| 模块 | 当前支持 |
| --- | --- |
| 邀请码 | 可选或必填、默认单次永久有效，支持自定义可用次数（1–1000）与有效时长（0–8760 小时）、批量生成及按可用/全部状态导出（CSV 含剩余次数与过期时间）；同时保留本站注册与验证规则 |
| 正版 Minecraft 验证 | 默认关闭（`wishingskin.minecraft`）；通过 Microsoft / Xbox Live / XSTS / Minecraft Services 校验 Java 版持有状态并显式绑定，不改变已有角色 UUID |
| 积分系统 | 默认关闭；支持北京时间每日签到奖励、上传消耗、新建角色消耗，以及活动积分码批量生成、停用、TXT/CSV 导出和用户原子兑换 |
| OIDC 登录 | 最多 12 个提供商；支持主动绑定、弹窗确认账号、直接登录或按本站规则注册 |
| 本站 OAuth2 | 授权码 + PKCE S256，支持公开/机密客户端、应用权限白名单、OIDC 发现、RS256 ID Token、Refresh Token 轮换、撤销、内省与窄范围只读 API（`/oauth/api/{characters,textures,points,minecraft}`） |
| 外部账号连接 | AuthMe 只读 MySQL 与通用 HTTP 主动验证绑定；不保存外部密码，也不替代本站登录密码 |
| S3 对象存储 | 保留本地副本、优先远端读取并校验 hash（异常自动回退本地）、旧材质幂等同步与远端分页回收 |
| 社区插件 | Go SDK 源码插件，以及通过 ZIP / 静态市场源安装的动态可执行插件；支持独立配置、热加载、路由、页面、任务、KV 数据、SQL 迁移、iframe 前端和持久事件 |
| Webhook | 支持 HMAC-SHA256 签名、持久队列投递、失败重试与最近 50 条投递历史 |

### 明确边界

- **运行安全**：源码插件与宿主同进程运行，动态插件在独立子进程运行，但两者均具备宿主进程权限，不提供操作系统级沙箱，请只安装可信来源。
- **插件市场**：仅支持维护者自建的静态 JSON 目录，项目不提供中心化插件托管商店。
- **暂未支持**：Passkey 无密码登录尚未提供；当前所有 OAuth2 第三方 API Scope 仅开放只读访问，不开放写入或管理接口。

## 运维与迁移

- **数据库**：支持 MySQL 8 与 PostgreSQL，提供 `/healthz`、`/readyz` 健康检查与字段级管理操作审计（支持 CSV 导出）。
- **备份与恢复**：支持每日按 IANA 时区定时备份、完整性校验、按份数自动清理和离线 CLI 隔离恢复；备份包含本地材质、动态插件包、KV 与插件 SQL 表（32 字节设置密钥须单独保管）。恢复要求使用同 schema 版本程序与独立空目标，不支持在线覆盖或自动降级；插件 SQL 表仅支持恢复到相同数据库引擎，含生成列或循环外键依赖的表需按插件自身手册备份。
- **存储维护与 CDN**：孤立文件回收仅清理无数据库引用且超过 1 小时的文件；公开材质 CDN 仅加速已审核公开文件并使用短期签名 URL（1–60 秒）。
- **Blessing Skin 迁移**：支持固定版本 BS 6.0.2 及指定 Yggdrasil 插件，保留账号、角色实际 UUID、材质、衣柜与声明范围内的历史数据；未知插件、任意运营配置和 PHP 插件不自动迁入，详见[BS 来源契约](bs-source-contract.md)和[迁移手册](migration-runbook.md)。
